One funny line a hopeless tech support agent says to a desperate customer, for the make.fun competition "Have You Tried Turning It Off?".

The entry:

> Have you tried turning it off and on again? Wonderful — now do it once more, slower, so the computer knows we mean it.

Run `main.ts` with Deno; it writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
